# CLAUDE.md

Context for Claude sessions working on this repository. This repo is **public**: never add secrets,
tokens, client names, client data or anything above TLP:CLEAR to it, including in this file.

## What this is

The website of **Strata Cyber**, live at https://stratacyber.com.br. Static site generated by `build.py`
from Markdown, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`
and daily at 06:00 BRT (that daily run is what publishes future-dated articles).

- English at `/`, Portuguese at `/pt/`. URLs and file names are English in both languages.
- The only interactive element is the Calendly embed (loaded on scroll). No CMS, logins, forms,
  analytics or cookies. Keep it that way.
- Settings (Calendly link, contact email, LinkedIn) live in `site.toml`.

## Publishing an article

Follow `WRITING.md`; it is the source of truth. In short:

1. Copy `content/articles/_template.md` to `content/articles/en/<slug>.md` and the Portuguese version
   to `content/articles/pt/<slug>.md`. **Same English slug in both** so they link to each other.
2. TOML front matter between `+++` lines: `title`, `summary`, `date` (unquoted; a future date publishes
   on that day), optional `kind`, `author`, `tlp` (only `"CLEAR"`; the build refuses anything else),
   `severity`, `draft`, `updated`.
3. Example indicators must be impossible to belong to anyone: domains ending in `.example`, IPs from
   `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`, always defanged (`example[.]com`, `hxxps://`).
4. Write both languages; Portuguese is Brazilian Portuguese, natural, not a literal translation.
5. Show the owner the draft and wait for approval before publishing. Then build locally
   (`python build.py`), commit, push, and confirm the article URL returns 200 on the live site.

Voice (from the brand guidelines): specific, prioritised, calibrated (estimative language with
probability ranges and a confidence level, e.g. "likely (55–80%), moderate confidence"), composed.
No hype, no fear-selling, no exclamation marks.

## Commands

```
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python build.py                  # build to dist/
.venv\Scripts\python build.py serve --drafts   # http://localhost:8000, includes drafts and future dates
.venv\Scripts\python tools\check_site.py        # after a build: links, anchors, alt text, meta, hreflang, sitemap
```

`dist/`, `.venv/` and `.claude/` are git-ignored. Pull requests run the same build and check
(`.github/workflows/check.yml`); GitHub Actions are pinned to commit SHAs and Dependabot proposes updates. Python 3.11+, one dependency (Markdown).

## Brand rules that the site must respect

- Colours (tokens in `static/css/site.css`): Garnet `#9E1F32`, Garnet Deep `#5E1420`, Garnet Tint `#F2DADF`,
  Ink `#15171A`, Charcoal `#2E3236`, Slate `#5B6168`, Stone `#A7A9A6`, Limestone `#E7E3DC`, Paper `#F6F4EF`.
- Logo: Charcoal on light backgrounds; White or Paper on Ink or Garnet. **Garnet only for the knight
  symbol on its own**, never the full logo or the wordmark.
- Type: Archivo Expanded (headings), Archivo (body), JetBrains Mono (labels, indicators, code).
  All self-hosted in `static/fonts/`; do not add font CDNs.
- No drop shadows. `static/brand/` and the favicons/OG images are generated from the
  brand kit by `tools/brand_assets.py`; regenerate rather than hand-edit.
- `static/brand/strata-cyber-logo-charcoal.png` is the public logo URL the brand kit's Google Docs and
  Slides builders embed. Keep that path stable.

## Security and hosting

- Content-Security-Policy is a meta tag in `build.py`; only this origin and Calendly are allowed.
  Adding any third-party script, font or frame needs a deliberate CSP change.
- DNS (Registro.br) and email authentication are documented in `README.md` under "Live setup".
  Only Google Workspace may send as the domain; a new sending service must be added to the single SPF
  record. DMARC is at `p=quarantine`, planned to move to `p=reject`.
- Commits use the repository-only identity `Strata Cyber <strata-cyber@users.noreply.github.com>`;
  don't commit with a personal email.
